# Система контроля ознакомления сотрудников с документами

Веб-приложение для локального сервера: учёт документов, назначение сотрудникам/подразделениям,
регистрация факта ознакомления, статусы (изучено / не изучено / просрочено), уведомления,
отчёты по подразделениям с выгрузкой в Excel и PDF, история ознакомления с поиском.

## Требования
- Node.js версии 18 или выше (проверялось на Node 22)

## Установка и запуск

1. Распакуйте архив, откройте терминал в папке проекта.
2. Установите зависимости:
   ```
   npm install
   ```
3. Запустите сервер:
   ```
   npm start
   ```
4. Откройте в браузере: **http://localhost:3000**

Порт по умолчанию — 3000. Изменить можно переменной окружения `PORT`, например:
```
PORT=8080 npm start
```

## Вход в систему

При первом запуске автоматически создаётся администратор:
- **Логин:** `admin`
- **Пароль:** `admin123`

Сразу после первого входа рекомендуется сменить пароль (Сотрудники → редактировать
администратора → указать новый пароль).

Обычные сотрудники могут зарегистрироваться самостоятельно на странице входа
(вкладка «Регистрация»): фамилия, имя, отчество, табельный номер, подразделение, логин, пароль.
Также администратор может создавать сотрудников вручную в разделе «Сотрудники».

## Возможности администратора
- **Документы** — загрузка файла документа, название, описание, срок ознакомления (по умолчанию
  7 календарных дней), назначение конкретным сотрудникам и/или целым подразделениям, дозначение
  дополнительных сотрудников позже, просмотр статуса ознакомления по каждому назначенному, удаление.
- **Сотрудники** — добавление, редактирование, удаление; указание Ф.И.О., табельного номера,
  подразделения, должности, непосредственного руководителя, логина/пароля, роли (администратор/сотрудник),
  активности учётной записи.
- **Подразделения** — добавление, редактирование, удаление.
- **Отчёты** — по каждому подразделению: процент изучения, список не ознакомившихся сотрудников,
  сроки просрочки; выгрузка в Excel (.xlsx) и PDF.
- **История** — полный журнал назначений/ознакомлений с фильтрами по сотруднику, документу и периоду,
  выгрузка в Excel.

## Возможности сотрудника
- Просмотр списка назначенных документов и их статусов.
- Скачивание файла документа.
- Подтверждение факта ознакомления (кнопка «Ознакомлен(а)») — фиксируются дата, время и Ф.И.О.
- Уведомления: о назначении нового документа и о просрочке (после 7 дней с момента публикации,
  если документ не изучен — уведомление приходит и сотруднику, и его непосредственному руководителю).

## Автоматический контроль просрочки
Каждый час (и при каждом обращении сотрудника к своим документам) система пересчитывает статусы:
если срок ознакомления истёк, а документ не изучен — статус меняется на «Просрочено» и
автоматически создаются уведомления сотруднику и его руководителю.

## Хранение данных
Все данные (пользователи, подразделения, документы, назначения, история, уведомления) хранятся
в локальной базе SQLite: `data/app.db`. Файлы документов сохраняются в папке `uploads/`.
Резервное копирование = копирование этих двух объектов.

## Структура проекта
```
doc-control-app/
├── server.js           # основной сервер и все API-маршруты
├── db.js                # инициализация БД и схема таблиц
├── statusEngine.js      # логика статусов и просрочки
├── package.json
├── data/app.db           # база данных SQLite (создаётся автоматически)
├── uploads/              # файлы загруженных документов
└── public/               # фронтенд (HTML/CSS/JS)
    ├── index.html         # страница входа / регистрации
    ├── admin.html + admin.js   # панель администратора
    ├── user.html + user.js     # панель сотрудника
    └── style.css
```

## Запуск как фоновой службы (опционально)
Для постоянной работы на сервере можно использовать, например, `pm2`:
```
npm install -g pm2
pm2 start server.js --name doc-control
pm2 save
```
